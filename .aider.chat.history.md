#### How to implement bubble sort in c++  

This is a bit outside the scope of analyzing your repository, but here's a simple bubble sort in C++:

```cpp
void bubbleSort(int arr[], int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
            }
        }
    }
}
```

**How it works:**
- The outer loop runs `n-1` passes
- The inner loop compares adjacent elements and swaps them if out of order
- Each pass "bubbles" the largest unsorted element to its correct position

**Time complexity:** O(n²) average and worst case.

#### How to implement bubble sort in c++

```cpp
#include <iostream>
#include <vector>

void bubbleSort(std::vector<int>& arr) {
    int n = arr.size();
    for (int i = 0; i < n - 1; i++) {
        for (int j = 0; j < n - i - 1; j++) {
            if (arr[j] > arr[j + 1]) {
                std::swap(arr[j], arr[j + 1]);
            }
        }
    }
}

int main() {
    std::vector<int> arr = {64, 34, 25, 12, 22, 11, 90};

    bubbleSort(arr);

    for (int x : arr) {
        std::cout << x << " ";
    }
    return 0;
}
```

**How it works:**
1. The outer loop runs `n-1` times.
2. The inner loop compares adjacent elements and swaps them if they are in the wrong order.
3. After each pass of the outer loop, the largest unsorted element "bubbles up" to its correct position.

**Time complexity:**
- Worst/Average case: O(n²)
- Best case: O(n) with an optimized version that detects if no swaps were made.
